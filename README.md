# Econ Metrics Project

Проектная работа по дисциплине «Эконометрика 2 (углубленный курс)».

Тема проекта: оценивание гедонистической ценовой функции для автомобилей марок Geely, Haval и Chery с помощью моделей множественной регрессии.

## Описание проекта

Цель проекта — построить и интерпретировать эконометрическую модель, объясняющую формирование цены автомобилей китайских марок на российском рынке.

В рамках работы были собраны данные с auto.ru, проведены очистка и предобработка данных, выполнен графический анализ, подобрана функциональная форма модели, проверены предпосылки теоремы Гаусса — Маркова, а также построены альтернативные спецификации, включая квантильную регрессию.

Зависимая переменная — цена автомобиля в рублях. Для автомобилей с ценовым диапазоном использовалась средняя цена между минимальным и максимальным значением.

## Данные

Датасет содержит объявления об автомобилях марок Geely, Haval и Chery.

Основные группы признаков:

### Целевая переменная

* `price` — цена автомобиля в рублях.

### Технические характеристики

* `power_1` — объем двигателя;
* `power_2` — мощность двигателя в лошадиных силах;
* `fuel_type` — тип топлива;
* `gearbox` — тип коробки передач;
* `drive` — тип привода.

### Визуальные и идентификационные характеристики

* `brand` — марка автомобиля;
* `model` — модель автомобиля;
* `color` — цвет кузова.

### Эксплуатационные характеристики

* `mileage` — пробег;
* `year` — год выпуска;
* `age` — возраст автомобиля.

### Географические признаки

* `city` — город продажи;
* `city_group` — агрегированная группа города.

### Производные признаки

* `generation` — поколение автомобиля;
* `model_popularity` — популярность модели в датасете;
* `color_group` — агрегированная группа цвета;
* `base_model` — базовая модель;
* `car_class` — класс автомобиля;
* `power_density` — удельная мощность;
* `is_new` — флаг нового автомобиля;
* `is_restyling` — флаг рестайлинга;
* `is_pro` — флаг версии Pro;
* `is_max` — флаг версии Max;
* `is_premium` — флаг премиальной версии.

## Методология

Работа включает следующие этапы:

1. Сбор данных с auto.ru.
2. Очистка и предобработка данных.
3. Создание производных признаков.
4. Первичный графический анализ.
5. Анализ распределений и корреляций.
6. Отбор признаков для модели.
7. Подбор функциональной формы.
8. Оценивание моделей множественной регрессии.
9. Проверка эконометрических предпосылок.
10. Оценивание итоговой модели с робастными стандартными ошибками.
11. Построение прогноза и доверительного интервала.
12. Оценивание квантильной регрессии.
13. Сравнение альтернативных спецификаций.

## Итоговая модель

В качестве итоговой спецификации используется модель с логарифмированной зависимой переменной:

```text
log(price) = 11.3904
             - 0.3728 log(age)
             + 0.0531 brand_Geely
             + 0.0477 is_restyling
             + 0.0824 color_group_Холодные
             + 0.6618 log(power_2)
             + 0.0515 city_group_Москва
             - 0.7501 gearbox_механика
             + 0.0542 drive_полный
             - 0.0463 car_class_Crossover
             + ε
```

## Основные выводы

* Возраст автомобиля отрицательно связан с ценой: чем старше автомобиль, тем ниже его стоимость.
* Мощность двигателя положительно связана с ценой.
* Автомобили Geely в среднем дороже при прочих равных.
* Рестайлинг положительно связан с ценой.
* Автомобили холодных цветов в среднем дороже.
* Автомобили из Москвы дороже при прочих равных.
* Механическая коробка передач значительно снижает цену.
* Полный привод положительно связан с ценой.
* Для модели была выявлена гетероскедастичность, поэтому использовались робастные стандартные ошибки типа HC3.
* Квантильная регрессия показала, что влияние факторов различается на разных участках ценового распределения.

## Эконометрические проверки

В проекте были использованы следующие проверки и тесты:

* анализ корреляций;
* проверка мультиколлинеарности;
* тест Бройша — Пагана;
* тест Уайта;
* тест Рамсея RESET;
* тест Шапиро — Уилка;
* тест Жака — Бера;
* тест Бокса — Кокса;
* PE-тест;
* F-тест значимости модели в целом;
* t-тесты значимости отдельных коэффициентов;
* проверка полноранговости матрицы регрессоров;
* расчет робастных стандартных ошибок HC3.
